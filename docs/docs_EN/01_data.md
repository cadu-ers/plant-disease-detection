- [PlantVillage Dataset (Kaggle)](https://www.kaggle.com/datasets/emmarex/plantdisease)

We use a subset of the dataset, with the **tomato** and **potato** classes
(13 classes in total).

## Format and resolution

Summary of all images in `data/`, generated by `python -m dados.data_overview`
([`reports/pi/dados/resumo_dados.csv`](../../reports/pi/dados/resumo_dados.csv)): there are
18,163 images in 13 classes, all **256x256 pixels**, in **JPEG** format
(read from the file header; extensions vary between `.JPG`, `.jpg` and
`.jpeg`) and **RGB** color mode. One file that is not an image was found in
`data/` and is ignored by the scripts.

![One image per class](../../reports/pi/dados/exemplos_por_classe.png)

## Class imbalance

The largest class (`Tomato__Tomato_YellowLeaf__Curl_Virus`, 3,208 images) has
about 21 times more images than the smallest (`Potato___healthy`, 152). CNN
training compensates for this with balanced `class_weight`, and the SVMs with
`class_weight="balanced"` (see [CNN](04_cnn.md) and
[Hybrid classifier](05_hybrid_classifier.md)).

## Training / validation / test split

Stratified 70/15/15 split (seed 42) performed by `python -m dados.split_dataset`,
recorded in `data_split/split_manifest.csv` and summarized in
[`reports/pi/dados/split_summary.csv`](../../reports/pi/dados/split_summary.csv). The test set
is fixed and is never used for training or for hyperparameter selection.
